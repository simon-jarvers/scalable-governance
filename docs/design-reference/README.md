# Design reference

Source files exported from the [Scalable Governance Website](https://claude.ai/design/p/95490a91-0a7a-456d-9a1c-b758456ebc04) project in Claude Design. Kept here for reference while implementing the real site — not part of the build.

- `Landing Page Mockup v4.dc.html` — the mockup implemented as the current landing page (`index.html`).
- `SG Logo System.dc.html` — logo mark construction (golden-ratio nested circles), sizing rules, and color values for light/dark backgrounds.
- `support.js` — the Claude Design (`.dc.html`) runtime these prototypes depend on. Not used in the actual site; the landing page reimplements the relevant behavior (hover/active states, scroll effects) in plain CSS/JS.

These are prototypes, not production code — the implementation matches their visual output and behavior, not their internal structure.
